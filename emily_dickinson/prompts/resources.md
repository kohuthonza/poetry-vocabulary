# Emily Dickinson text resources

The user's reading corpus is **Poems: As She Preserved Them**. Source headings describe that project's fascicle/sheet/poem order, not Franklin or Johnson numbers. Search by first-line text after the initial ` - ` delimiter and identify the edition/manuscript actually consulted. Another edition is context evidence, not an exact replacement for the user's reading text.

For an approved fascicle, collect a usable **full-poem local file for every selected heading before the typo audit**. Record each file's poem heading, source URL and actual edition/transcription identity in the temporary source manifest. Verify that a candidate page contains the intended poem, not merely the same first line or a search result; read neighboring lines for each vocabulary item. If only another edition is accessible, keep its wording identified as comparative evidence and flag consequential variants for the user. Never conclude that the user's record is correct solely because it is plausible English, and never conclude that it is wrong solely because another edition differs. Keep these local files for vocabulary context and delete the temporary archive after completion.

When several poems share one anthology page, retrieve that page once and use the local Franklin splitter described in [tools/README.md](../../tools/README.md) to create separate full-poem files and compact provenance. It matches exact normalized first lines and stops on missing or ambiguous matches; inspect any alternative first line before supplying a mapping. This saves repeated page retrieval but does not change the edition standard above. Verify the generated poem text against the saved page when the verse layout looks uncertain.

- [Wikisource: Emily Dickinson](https://en.wikisource.org/wiki/Author:Emily_Dickinson): accessible on 2026-09-25; provides named collections and individual-poem links. Prefer a transcription tied to scans and identifiable edition information. Its listed historical collections and Johnson index must not be confused with the user's fascicle numbering. Follow through to the poem text before citing a reading.
- [PoemHunter: Emily Dickinson](https://www.poemhunter.com/emily-dickinson/): accessible on 2026-09-25 and useful as a secondary context/first-line lookup. Edition provenance may be unspecified; it cannot alone establish the exact reading in Poems: As She Preserved Them. Cross-check consequential differences against an identifiable edition or the user's text.
- [Emily Dickinson Archive](https://www.edickinson.org/): manuscript/editorial resource, but the historical prompt records an access error on 2026-09-10. Manuscript images/transcriptions were not verified in that run. Do not repeatedly retry each fascicle; revisit when the user requests it or there is evidence access has changed.
- [Poetry Foundation: Emily Dickinson](https://www.poetryfoundation.org/poets/emily-dickinson): likewise recorded inaccessible on 2026-09-10; no Franklin Reading Edition text was verified through that route. The same retry rule applies. A poet landing page is not a citation for an unseen poem text.

Use supplied text first where the exact edition matters. If no accessible source establishes its reading, describe the uncertainty and let the user resolve it; do not silently “correct” a variant using an unspecified web transcription. Preserve dashes and historical forms except for agreed changes. Use reliable dictionaries for uncertain lexical/historical meanings, not to reconstruct a poem. Record further access failures briefly and move to an accessible alternative without bypassing restrictions.
