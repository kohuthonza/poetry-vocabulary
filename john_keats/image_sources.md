# John Keats visual vocabulary

Use `jk-` for new image basenames derived from approved Visuals keywords. A resolved set has five numbered JPEGs in the active local Anki media directory. Anki stores the stable basename in its Visual field. Preserve established basenames and record each new set and its image sources below as files are saved.
